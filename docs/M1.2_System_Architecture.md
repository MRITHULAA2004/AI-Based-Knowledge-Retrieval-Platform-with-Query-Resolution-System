\### Architecture Overview



The system consists of a frontend interface, FastAPI backend, document ingestion pipeline, ChromaDB vector database, and a proposed multi-agent orchestration layer.



The five proposed agents are:

1\. Query Understanding Agent

2\. Clarification Agent

3\. Retrieval Agent

4\. Response Generation Agent

5\. Conversation Memory Agent



The architecture supports document ingestion, semantic retrieval, query processing, and context-grounded response delivery.
